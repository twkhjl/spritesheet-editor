# 格子播放清單設計

## 目標

允許使用者從 spritesheet 選取特定格子，建立可重複、可指定順序的播放清單。播放器不再只能依固定格線順序播放全部格子。

## 播放清單模型

- 格子編號從 1 開始，依左至右、由上而下編號。
- 播放清單儲存格子索引陣列，例如 `1 → 2 → 3 → 1`。
- 同一格可重複加入。
- 播放器依清單位置前進，動畫畫面及完整圖表游標使用該項目指向的原始格子。
- 播放讀數顯示「目前清單位置 / 清單長度」，並另外顯示目前格子編號。
- 欄數或列數改變時，清除既有清單並依目前排序模式重新建立，避免保留超出新格線的索引。

## 選格與編輯

- 完整圖表覆蓋可操作的格子按鈕。
- 點擊格子會將該格追加到播放清單尾端；再次點擊同一格會再次追加。
- 播放清單以有順序的項目顯示；每項標示格子編號。
- 點擊清單項目會移除該次出現，不影響相同格子的其他項目。
- 提供「清空」及「使用全部格子」操作。
- 清單為空時，播放與逐幀按鈕停用並顯示「請先選取要播放的格子」。

## 快速排序

提供下列模式：

- 左到右，再上到下：依 row-major 順序加入全部格子。
- 上到下，再左到右：依 column-major 順序加入全部格子。
- 反向：將目前播放清單反轉。
- 自訂順序：不自動改變清單，後續點格依點擊順序追加。

選擇前兩種模式會以該方向重新建立完整格線清單；選擇反向會反轉現有清單；手動追加或移除後，模式標示為「自訂順序」。

## 介面

- 格線設定下方新增「快速排序」選單。
- 動畫區下方新增水平播放清單，可捲動並顯示 `1 → 2 → 3 → 1`。
- 完整圖表中的格子顯示編號；目前播放格使用珊瑚色外框。
- 已加入播放清單的格子顯示加入次數徽章。
- 空清單訊息與控制狀態使用既有狀態區及停用樣式。

## 程式結構

- 在 `player-model.js` 新增：
  - `rowMajorSequence(columns, rows)`
  - `columnMajorSequence(columns, rows)`
  - `appendFrame(sequence, frameIndex)`
  - `removeSequenceItem(sequence, sequenceIndex)`
- `framePosition` 繼續以零起始原始格子索引計算座標。
- `app.js` 將目前播放位置與原始格子索引分開保存。

## 測試與驗收

- 3 × 2 的左到右序列為 `[0, 1, 2, 3, 4, 5]`。
- 3 × 2 的上到下序列為 `[0, 3, 1, 4, 2, 5]`。
- 同一格可產生 `[0, 1, 2, 0]`。
- 移除其中一次重複項目不影響其他項目。
- 頁面包含排序控制、播放清單及格子選取層。
- 瀏覽器實測可建立 `1 → 2 → 3 → 1`、播放、移除項目、反轉及清空。
- 清單為空時播放按鈕停用；重新選格後恢復。
